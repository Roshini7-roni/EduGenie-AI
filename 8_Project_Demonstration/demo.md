\# 8. Project Demonstration



\## Project Name



EduGenie – AI-Powered Personalized Learning Assistant



\## Demonstration Overview



The demonstration shows the main features of the EduGenie application and how learners can interact with the system.



\## Features Demonstrated



\### 1. AI Explanation



A learner enters an educational topic and receives an AI-generated explanation.



\### 2. Question and Answer



A learner enters a question and receives an answer related to the question.



\### 3. Summary



The application generates a concise summary from educational content.



\### 4. Quiz Generation



The application generates quiz questions for self-assessment.



\### 5. Personalized Learning Path



The application generates a structured learning path for a selected topic.



\### 6. Different Learning Levels



The application supports different explanation levels such as:



\- School

\- College

\- Advanced

\## Demonstration Steps



1\. Start the EduGenie application.

2\. Open the application in a web browser.

3\. Enter an educational question or topic.

4\. Select the required feature.

5\. Select the appropriate learning level where applicable.

6\. Submit the request.

7\. View the AI-generated result.

8\. Demonstrate the other educational features.



\## Expected Demonstration Result



The demonstration should show that EduGenie can provide educational assistance through AI-powered explanations, question answering, summarization, quiz generation, and personalized learning paths.
