\# 2. Requirement Analysis



\## Functional Requirements



\### FR1 – Topic Explanation



The system shall allow users to enter a topic and receive an AI-generated explanation.



\### FR2 – Learning Level



The system shall allow users to select an appropriate learning level such as:



\- School

\- College

\- Advanced



\### FR3 – Question Answering



The system shall accept user questions and generate relevant answers.



\### FR4 – Summarization



The system shall summarize educational text provided by the user.



\### FR5 – Quiz Generation



The system shall generate multiple-choice questions based on the requested topic or content.



\### FR6 – Learning Path



The system shall generate a structured learning path for a selected learning goal.



\## Non-Functional Requirements



\### Performance



The application should provide responses within a reasonable time depending on AI service availability.



\### Usability



The interface should be simple and easy for students to use.



\### Reliability



The application should handle API errors and invalid requests appropriately.



\### Security



API credentials must not be exposed in the public GitHub repository.



\### Maintainability



The project should use separate modules for major educational features.
